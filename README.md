# README.md

## Описание проекта

Данный набор Python-скриптов реализует автоматическое тестирование API для управления учителями и загрузки файлов. Основная задача — обеспечить корректную работу API через генерацию различных тестовых данных и запросов, используя структуру моделей и Pytest.

## Структура файлов

- **fixture_new_teacher.py**  
  Класс и фикстуры для создания, изменения, получения данных учителя через API. Обеспечивает авторизацию, формирование запросов (POST, PUT, GET) и обработку токенов, результатов и ошибок. \
  Все параметры и сценарии негативного тестирования настраиваются через фикстуры внутри тестового файла.

- **parameters_new_teacher.py**  
  Класс-генератор параметров учителя: случайные и валидные/невалидные значения типа, языка, стиля, описания и пр. Генерирует входные данные для тестов, включая негативные сценарии.

- **parameters_upload_file.py**  
  Класс-генератор параметров для загрузки файла. Гибко формирует входные данные: название, описание, тип файла, reference ID, валидность значений. Позволяет тестировать загрузку с разными входными данными и ожиданиями по статусу ответа.

- **test_new_teacher.py**  
  Основные тесты на Pytest. Проверяет флоу создания, изменения и получения данных учителя, а также загрузку файлов на соответствующие эндпоинты. Осуществляет assert по данным и коду ответа.

## Взаимодействие компонентов

- Тесты из **test_new_teacher.py** используют фикстуры и классы из **fixture_new_teacher.py** для работы с API.
- Аргументы и тестовые данные для запросов генерируются с помощью классов **parameters_new_teacher.py** и **parameters_upload_file.py**.
- Вся логика запросов к API и обработки ответов инкапсулирована в классе NewTeacher.
- Загрузка файла тестируется с помощью динамически сгенерированных параметров через upload endpoints.
- Внутри теста происходит последовательность: генерация параметров → вызовы API → assert результата.

## Пример сценария работы

1. Сгенерировать параметры учителя (валидные/невалидные).
2. Отправить POST-запрос для создания учителя.
3. Выполнить PUT-запрос для обновления учителя.
4. Получить GET-запросом данные, проверить соответствие ожиданиям.
5. Сгенерировать параметры для загрузки файла и отправить запрос, проконтролировать ответ.
